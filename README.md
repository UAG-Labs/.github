# Organization Asset Folder

Copy the contents of this `Organization` folder into the root of the **UAG-Labs/.github** repository.

After copying, the `.github` repo should look like this:

```text
.github/
  README.md
  profile/
    README.md
    assets/
      uag-labs-readme-banner.svg
      uag-labs-github-avatar.png
      uag-labs-icon-transparent.svg
```

GitHub will show `profile/README.md` on the UAG-Labs organization overview page.

The organization avatar is not applied from a repo. Upload it manually in:

```text
UAG-Labs → Settings → Profile → Organization profile picture
```

Use:

```text
profile/assets/uag-labs-github-avatar.png
```
